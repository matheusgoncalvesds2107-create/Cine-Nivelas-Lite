# Cinenovelas Lite - Android 6

Teste leve, sem AndroidX e sem bibliotecas nativas, com `minSdk 23` (Android 6.0).

## Gerar APK no GitHub
1. Envie todo o conteúdo deste ZIP para a raiz de um repositório GitHub.
2. Abra **Actions** > **Build APK** > **Run workflow**.
3. Ao terminar, baixe o artefato **Cinenovelas-Lite-Android6**.

## Fonte de dados
Base encontrada no APK analisado: `https://cinenovelas.xyz/v1/`
Rotas que a Lite tenta: `novels`, `home`, `sections`, `novel/{id}`, `season/{id}/episodes`.

A reprodução não foi ligada nesta versão porque a rota/fonte de vídeo ainda precisa ser confirmada. O projeto não contorna DRM nem mecanismos de proteção.
